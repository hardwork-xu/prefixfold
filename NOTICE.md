# Third-party attribution / 第三方归属

PrefixFold is an independent implementation of established attention identities. Cascade Attention and Hydragen provide the shared-prefix decomposition/grouping idea; online softmax and FlashAttention provide stable tiled accumulation. No third-party attention kernel source is copied. See [verified sources](research/sources.json) and [research](docs/en/RESEARCH.md).

PrefixFold 独立实现已有注意力恒等式。共享前缀分解与分组归属 Cascade Attention 和 Hydragen；稳定分块累加依据在线 softmax 与 FlashAttention。未复制第三方注意力内核代码。详见[中文研究说明](docs/zh/RESEARCH.md)。
